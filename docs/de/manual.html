Was ist ChameleonRecorder?

ChameleonRecorder ist ein headless, plug-and-play Multitrack-WAV-Recorder, der auf einem Raspberry Pi 4 (64-Bit) läuft. Er erkennt automatisch jedes klassenkonforme USB-Audio-Interface oder Digitalmischpult, nimmt unkomprimierte 24-Bit-Multitrack-WAV-Dateien direkt auf einen USB-Stick auf und bietet eine mobilfreundliche Web-Fernbedienung mit Live-Pegelanzeigen.

Kein Laptop. Keine DAW. Keine Treiber. Nur ein Raspberry Pi, ein USB-Audio-Interface und ein USB-Stick. Einschalten und aufnehmen.

Universelles USB-Audio

Erkennt automatisch klassenkonforme USB-Audio-Interfaces (Behringer UMC1820, UMC204HD, XR18, X32, MOTU AVB, Focusrite, RME, Zoom) mit 48 kHz mit 44.1 kHz Fallback.

Multi-Device-Aufnahme

Nimm mehrere USB-Interfaces gleichzeitig auf. Das Interface mit den meisten Kanälen wird der JACK-Master; zusätzliche Interfaces werden über alsa_in mit Drift-Kompensation gebunden.

Web-Fernbedienung

Vollständige Kontrolle von jedem Handy-, Tablet- oder Laptop-Browser auf Port :8080. Geräte- und kanalweises Scharfschalten, Live-Peak-Meter, Dateiverwaltung und ZIP-Download.

Fallback-WLAN-Hotspot

Wenn innerhalb von 25 Sekunden nach dem Boot kein bekanntes WLAN gefunden wird, erstellt ChameleonRecorder seinen eigenen Access Point (SSID: ChameleonRecorder, Passwort: chameleon123) unter http://10.42.0.1:8080.

ADAT-Clock-Sync

Erkennt automatisch gültige ADAT-Clock-Signale an Behringer UMC1820-Interfaces und schaltet sie auf externen ADAT-Clock-Sync für sample-genaue Multi-Unit-Aufnahmen um.

GPIO-Steuerung

Optionale physische Taster für Aufnahme/Stopp und Letzten löschen, plus eine Status-LED. Beide Taster gehalten = sicheres Herunterfahren.

Speicher verbinden

Schließe einen USB-Stick oder eine SSD formatiert als exFAT oder ext4 an einen der blauen USB-3.0-Ports an. Er wird automatisch unter /media/usb0 eingehängt. ext4 wird empfohlen, um das 4-GB-Dateigrößenlimit von FAT32 zu vermeiden.

Audio-Interfaces verbinden

Verbinde dein(e) USB-Audio-Interface(s) mit dem Raspberry Pi und schalte sie ein. ChameleonRecorder erkennt beim Boot automatisch alle USB-Audiogeräte. Das Interface mit den meisten Kanälen wird der JACK-Master; zusätzliche Interfaces werden über alsa_in gebunden.

Multi-Interface-Word-Clock / ADAT-Sync

Für sample-genaue Aufnahmen mit mehreren Units (z. B. 2x UMC1820 + 2x ADA8200):

  1. Setze ADA8200 #1 auf MASTER 48 kHz und verbinde dessen WORD CLOCK OUT (75 Ohm BNC) mit ADA8200 #2 (SLAVE WC IN)
  2. Verbinde ADAT OUT von ADA8200 #1 mit ADAT IN von UMC1820 #1, und ADAT OUT von ADA8200 #2 mit ADAT IN von UMC1820 #2
  3. Setze die Frontpanel-Taste OPT I/O an beiden UMC1820-Units auf ADAT
  4. Beim Boot (oder beim Drücken von Re-Scan USB Audio Device) erkennt der Pi automatisch das gültige ADAT-Signal und schaltet beide auf externen ADAT-Clock-Sync um

Web-Fernbedienung

Die Web-Fernbedienung ist von jedem Browser auf Port :8080 erreichbar. Sie bietet vollständige Kontrolle über die Aufnahme, ohne dass Bildschirm, Tastatur oder Maus am Pi angeschlossen sein müssen.

Aufnahmeformat

Aufnahmen werden als unkomprimierte 24-Bit-WAV-Dateien mit 48 kHz gespeichert (oder 44.1 kHz, falls 48 kHz fehlschlägt). Jede Datei wird mit einem Zeitstempel benannt: YYYYMMDD_HHMMSS.wav. Dateien werden direkt auf den USB-Stick unter /media/usb0/ gespeichert.

Tipp: Nutze einen USB-3.0-Stick oder eine SSD für beste Leistung. USB-2.0-Laufwerke können bei Multitrack-Aufnahmen durch Bandbreitenbegrenzung Samples verlieren.

Clock-Sync und Multi-Device-Aufnahme

ChameleonRecorder unterstützt die gleichzeitige Aufnahme mehrerer USB-Audio-Interfaces. Das System handhabt die Clock-Synchronisation automatisch:

Wie es funktioniert

  1. Beim Boot scannt startcapiture alle USB-Audiokarten über /proc/asound/cards
  2. Karten werden nach Anzahl der Aufnahmekanäle sortiert (absteigend) — die Karte mit den meisten Kanälen wird der JACK-Master
  3. Der primäre JACK-Server startet auf der Master-Karte mit 48 kHz (mit 44.1 kHz Fallback)
  4. Zusätzliche Interfaces werden über alsa_in mit adaptiver Drift-Kompensation gebunden
  5. Für Behringer UMC1820: Wenn ein gültiges ADAT-Signal am optischen Eingang erkannt wird, wird die Clock-Quelle automatisch auf externen ADAT umgeschaltet

ADAT-Clock-Sync-Erkennung

Wenn ein UMC1820 erkannt wird, prüft ChameleonRecorder die Optical In ADAT/SMUX Validity-Steuerung. Wenn das Signal gültig ist, setzt es die Clock-Quelle auf 2 (externer ADAT). Wenn nicht, setzt es sie auf 0 (intern). Dies geschieht automatisch beim Boot und beim Drücken von Re-Scan USB Audio Device.

Drift-Kompensation

Wenn mehrere Interfaces unabhängig laufen (keine Word-Clock-Verbindung), driften ihre Sample-Clocks leicht. JACKs alsa_in-Mechanismus bietet adaptive Drift-Kompensation — er passt das Resampling-Verhältnis periodisch an, um alle Kanäle synchron zu halten. Für kritische Multi-Unit-Setups nutze eine Word-Clock- oder ADAT-Verbindung für sample-genaue Synchronisation.

Dateiverwaltung

Alle Aufnahmen werden auf dem USB-Stick unter /media/usb0/ gespeichert. Die Web-Fernbedienung bietet vollständige Dateiverwaltung:

AktionWie man es macht
Letzten Take löschenDrücke Delete Last Recording auf der Web-Fernbedienung (oder GPIO-Taster)
Einzelne Datei löschenKlicke Delete neben der Datei in der Aufnahmenliste
Einzelne WAV herunterladenKlicke Download neben der Datei
Alle als ZIP herunterladenKlicke Download All (.zip) — bündelt alle WAVs in ein zeitgestempeltes Archiv
Warnung: Das Löschen von Dateien ist dauerhaft. Es gibt kein Rückgängig. Lade wichtige Aufnahmen vor dem Löschen herunter.

Fehlerbehebung

Kein Audio erkannt

  • Prüfe, ob dein USB-Audio-Interface verbunden und eingeschaltet ist
  • Verifiziere, dass das Interface klassenkonform ist (keine Treiber nötig)
  • Drücke Re-Scan USB Audio Device auf der Web-Fernbedienung
  • SSH in den Pi und führe cat /proc/asound/cards aus, um zu sehen, ob das Gerät erkannt wird
  • Probiere einen anderen USB-Port (bevorzugt blaue USB-3.0-Ports)

USB-Speicher wird nicht eingehängt

  • Stelle sicher, dass der USB-Stick als exFAT oder ext4 formatiert ist (nicht FAT32 oder NTFS)
  • Prüfe, dass das Laufwerk an einem blauen USB-3.0-Port steckt
  • SSH in den Pi und führe lsblk aus, um zu sehen, ob das Laufwerk erkannt wird
  • Prüfe dmesg | tail auf Mount-Fehler
  • Probiere einen anderen USB-Stick oder formatiere ihn neu

WLAN-Hotspot erscheint nicht

  • Warte mindestens 25 Sekunden nach dem Boot — der Hotspot startet nach einer 25-Sekunden-Verzögerung
  • Wenn der Pi mit einem bekannten WLAN-Netzwerk verbunden ist, wird er KEINEN Hotspot erstellen (das ist so gewollt)
  • Prüfe, dass der WLAN-Ländercode korrekt gesetzt ist (Standard ist DE, wenn nicht gesetzt)
  • SSH in den Pi und prüfe systemctl status wifi-fallback.service
  • Starte den Hotspot manuell: sudo nmcli device wifi hotspot ifname wlan0 con-name ChameleonHotspot ssid "ChameleonRecorder" password "chameleon123"
