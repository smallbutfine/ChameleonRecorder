Cómo Flashear con Raspberry Pi Imager

  1. Descargar la imagen: Descarga el último daw-image.img.xz de la página de Releases
  2. Abrir Raspberry Pi Imager: Descarga y lanza el oficial Raspberry Pi Imager en tu ordenador Windows, macOS o Linux
  3. Elegir Dispositivo: Haz clic en Choose Device y selecciona Raspberry Pi 4
  4. Elegir SO: Haz clic en Choose OS, desplázate hasta el final, selecciona Use custom y elige el archivo daw-image.img.xz descargado
  5. Elegir Almacenamiento: Inserta tu tarjeta microSD (16 GB o mayor) y selecciónala en Choose Storage
  6. OS Customisation opcional: Haz clic en Next y elige Edit Settings si quieres preconfigurar tus credenciales Wi-Fi de casa/estudio, establecer el código de país Wi-Fi, o añadir una contraseña/clave SSH para el usuario recorder. Si omites este paso (clic en No), la Pi iniciará automáticamente su hotspot Wi-Fi ChameleonRecorder independiente en el primer arranque
  7. Escribir la Imagen: Haz clic en Yes para confirmar y espera a que Raspberry Pi Imager termine de escribir y verificar la tarjeta SD
  8. Arrancar y Grabar: Inserta la tarjeta microSD en tu Raspberry Pi 4B, conecta tu memoria USB y la(s) interfaz(es) de audio USB, y enciéndela

Primer Arranque

  1. Inserta la tarjeta microSD en la Raspberry Pi 4B
  2. Conecta una memoria USB (exFAT o ext4) en un puerto USB 3.0 azul
  3. Conecta tu(s) interfaz(es) de audio USB
  4. Enciende la Pi
  5. Espera ~25 segundos — si no se encuentra Wi-Fi conocido, aparece el hotspot ChameleonRecorder
  6. Conecta al hotspot y abre http://10.42.0.1:8080

Hotspot de Respaldo vs. Wi-Fi de Casa

ChameleonRecorder soporta dos modos de conexión:

ModoCuándo se activaURL
Wi-Fi de Casa / EstudioSi preconfiguraste Wi-Fi en Raspberry Pi Imager, o si la Pi se conectó previamente a una red conocidahttp://<PI_IP>:8080 o http://DAW.local:8080
Hotspot de RespaldoSi no se encuentra Wi-Fi conocido en los 25 segundos posteriores al arranquehttp://10.42.0.1:8080 (SSID: ChameleonRecorder, Contraseña: chameleon123)
Consejo: El hotspot de respaldo es perfecto para uso en escenario y ensayo — no se necesita router. Solo conecta tu teléfono o portátil directamente al Wi-Fi de la Pi.

Requisitos del Sistema

ComponenteRequisito
OrdenadorRaspberry Pi 4 Model B (64 bits), 2 GB RAM mínimo (4 GB recomendado)
AlmacenamientoTarjeta microSD (16 GB+) para el SO, memoria USB o SSD (exFAT o ext4) para grabaciones
Interfaz de AudioCualquier interfaz de audio USB clase-conforme o mezclador digital (48 kHz)
AlimentaciónFuente de alimentación USB-C (3A recomendado)

Acceso SSH
