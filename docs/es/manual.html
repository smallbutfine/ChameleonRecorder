¿Qué es ChameleonRecorder?

ChameleonRecorder es un grabador multitrack WAV headless y plug-and-play que funciona en una Raspberry Pi 4 (64 bits). Detecta automáticamente cualquier interfaz de audio USB clase-conforme o consola de mezcla digital, graba archivos WAV multitrack sin compresión de 24 bits directamente en una memoria USB, y proporciona un control remoto web apto para móviles con medidores de nivel en vivo.

Sin portátil. Sin DAW. Sin controladores. Solo una Raspberry Pi, una interfaz de audio USB y una memoria USB. Enciende y graba.

Audio USB Universal

Detecta automáticamente interfaces de audio USB clase-conformes (Behringer UMC1820, UMC204HD, XR18, X32, MOTU AVB, Focusrite, RME, Zoom) a 48 kHz con alternativa de 44.1 kHz.

Grabación Multi-Dispositivo

Graba múltiples interfaces USB simultáneamente. La interfaz con más canales se convierte en el maestro JACK; las interfaces adicionales se vinculan mediante alsa_in con compensación de deriva.

Control Remoto Web

Control completo desde cualquier navegador de teléfono, tablet o portátil en el puerto :8080. Armado por dispositivo y por canal, medidores de pico en vivo, gestión de archivos y descarga ZIP.

Punto de Acceso Wi-Fi de Respaldo

Si no se encuentra ningún Wi-Fi conocido en los 25 segundos posteriores al arranque, ChameleonRecorder crea su propio punto de acceso (SSID: ChameleonRecorder, Contraseña: chameleon123) en http://10.42.0.1:8080.

Sync de Reloj ADAT

Detecta automáticamente señales de reloj ADAT válidas en interfaces Behringer UMC1820 y las cambia a sync de reloj ADAT externo para grabación multi-unidad sample-perfecta.

Controles GPIO

Pulsadores físicos opcionales para Grabar/Parar y Borrar Última, más un LED de estado. Ambos pulsadores mantenidos = apagado seguro.

Conectar el almacenamiento

Conecta una memoria USB o SSD formateada como exFAT o ext4 en uno de los puertos USB 3.0 azules. Se monta automáticamente en /media/usb0. Se recomienda ext4 para evitar el límite de tamaño de archivo de 4 GB de FAT32.

Conectar interfaces de audio

Conecta tu(s) interfaz(es) de audio USB a la Raspberry Pi y enciéndelas. ChameleonRecorder detecta automáticamente todos los dispositivos de audio USB al arrancar. La interfaz con más canales se convierte en el maestro JACK; las interfaces adicionales se vinculan mediante alsa_in.

Word clock multi-interfaz / sync ADAT

Para grabación sample-perfecta con múltiples unidades (p. ej. 2x UMC1820 + 2x ADA8200):

  1. Configura ADA8200 #1 en MASTER 48 kHz y conecta su WORD CLOCK OUT (BNC 75ohm) a ADA8200 #2 (SLAVE WC IN)
  2. Conecta ADAT OUT de ADA8200 #1 a ADAT IN de UMC1820 #1, y ADAT OUT de ADA8200 #2 a ADAT IN de UMC1820 #2
  3. Configura el botón del panel frontal OPT I/O en ambas unidades UMC1820 en ADAT
  4. Al arrancar (o al pulsar Re-Scan USB Audio Device), la Pi detecta automáticamente la señal ADAT válida y cambia ambas a sync de reloj ADAT externo

Formato de grabación

Las grabaciones se guardan como archivos WAV de 24 bits sin compresión a 48 kHz (o 44.1 kHz si 48 kHz falla). Cada archivo se nombra con una marca de tiempo: YYYYMMDD_HHMMSS.wav. Los archivos se guardan directamente en la memoria USB en /media/usb0/.

Consejo: Usa una memoria USB 3.0 o SSD para el mejor rendimiento. Las unidades USB 2.0 pueden perder muestras durante la grabación multitrack debido a limitaciones de ancho de banda.

Sync de Reloj y Grabación Multi-Dispositivo

ChameleonRecorder soporta la grabación de múltiples interfaces de audio USB simultáneamente. El sistema maneja automáticamente la sincronización de reloj:

Cómo funciona

  1. Al arrancar, startcapiture escanea todas las tarjetas de audio USB mediante /proc/asound/cards
  2. Las tarjetas se ordenan por número de canales de captura (descendente) — la tarjeta con más canales se convierte en el maestro JACK
  3. El servidor JACK primario arranca en la tarjeta maestra a 48 kHz (con alternativa de 44.1 kHz)
  4. Las interfaces adicionales se vinculan mediante alsa_in con compensación de deriva adaptativa
  5. Para Behringer UMC1820: si se detecta una señal ADAT válida en la entrada óptica, la fuente de reloj se cambia automáticamente a ADAT externo

Detección de sync de reloj ADAT

Cuando se detecta un UMC1820, ChameleonRecorder comprueba el control Optical In ADAT/SMUX Validity. Si la señal es válida, establece la fuente de reloj en 2 (ADAT externo). Si no, la establece en 0 (interno). Esto ocurre automáticamente al arrancar y al pulsar Re-Scan USB Audio Device.

Compensación de deriva

Cuando múltiples interfaces funcionan independientemente (sin conexión de word clock), sus relojes de muestra se desvían ligeramente. El mecanismo alsa_in de JACK proporciona compensación de deriva adaptativa — ajusta periódicamente la relación de remuestreo para mantener todos los canales sincronizados. Para configuraciones multi-unidad críticas, usa una conexión de word clock o ADAT para sync sample-perfecta.

Todas las grabaciones se almacenan en la memoria USB en /media/usb0/. El control remoto web proporciona gestión completa de archivos:

AcciónCómo hacerlo
Borrar última tomaPulsa Delete Last Recording en el control remoto web (o botón GPIO)
Borrar archivo individualHaz clic en Delete junto al archivo en la lista de Grabaciones
Descargar WAV individualHaz clic en Download junto al archivo

Resolución de Problemas

No se detecta audio

  • Comprueba que tu interfaz de audio USB esté conectada y encendida
  • Verifica que la interfaz sea clase-conforme (sin drivers necesarios)
  • Pulsa Re-Scan USB Audio Device en el control remoto web
  • Entra por SSH a la Pi y ejecuta cat /proc/asound/cards para ver si el dispositivo es detectado
  • Prueba un puerto USB diferente (preferiblemente puertos USB 3.0 azules)

El almacenamiento USB no se monta

  • Asegúrate de que la memoria USB esté formateada como exFAT o ext4 (no FAT32 ni NTFS)
  • Comprueba que el disco esté conectado a un puerto USB 3.0 azul
  • Entra por SSH a la Pi y ejecuta lsblk para ver si el disco es detectado
  • Comprueba dmesg | tail para errores de montaje
  • Prueba otra memoria USB o reformatea

El hotspot Wi-Fi no aparece

  • Espera al menos 25 segundos tras el arranque — el hotspot empieza tras un retraso de 25 segundos
  • Si la Pi está conectada a una red Wi-Fi conocida, NO creará un hotspot (esto es por diseño)
  • Comprueba que el código de país Wi-Fi esté configurado correctamente (por defecto DE si no se establece)
  • Entra por SSH a la Pi y comprueba systemctl status wifi-fallback.service
  • Inicia el hotspot manualmente: sudo nmcli device wifi hotspot ifname wlan0 con-name ChameleonHotspot ssid "ChameleonRecorder" password "chameleon123"
