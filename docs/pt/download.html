Como Flashar com o Raspberry Pi Imager

  1. Baixar a imagem: Baixe o último daw-image.img.xz da página de Releases
  2. Abrir o Raspberry Pi Imager: Baixe e inicie o oficial Raspberry Pi Imager no seu computador Windows, macOS ou Linux
  3. Escolher o Dispositivo: Clique em Choose Device e selecione Raspberry Pi 4
  4. Escolher o SO: Clique em Choose OS, role até o final, selecione Use custom e escolha o arquivo daw-image.img.xz baixado
  5. Escolher o Armazenamento: Insira seu cartão microSD (16 GB ou maior) e selecione-o em Choose Storage
  6. OS Customisation opcional: Clique em Next e escolha Edit Settings se quiser pré-configurar suas credenciais Wi-Fi de casa/estúdio, definir o código do país Wi-Fi, ou adicionar uma senha/chave SSH para o usuário recorder. Se pular esta etapa (clique em No), o Pi iniciará automaticamente seu hotspot Wi-Fi ChameleonRecorder standalone na primeira inicialização
  7. Gravar a Imagem: Clique em Yes para confirmar e aguarde o Raspberry Pi Imager terminar de gravar e verificar o cartão SD
  8. Iniciar e Gravar: Insira o cartão microSD no seu Raspberry Pi 4B, conecte seu pen drive e interface(s) de áudio USB, e ligue-o

Primeira Inicialização

  1. Insira o cartão microSD no Raspberry Pi 4B
  2. Conecte um pen drive (exFAT ou ext4) em uma porta USB 3.0 azul
  3. Conecte sua(s) interface(s) de áudio USB
  4. Ligue o Pi
  5. Espere ~25 segundos — se nenhum Wi-Fi conhecido for encontrado, o hotspot ChameleonRecorder aparece
  6. Conecte ao hotspot e abra http://10.42.0.1:8080

Hotspot de Fallback vs. Wi-Fi de Casa

O ChameleonRecorder suporta dois modos de conexão:

ModoQuando ativaURL
Wi-Fi de Casa / EstúdioSe você pré-configurou o Wi-Fi no Raspberry Pi Imager, ou se o Pi já se conectou a uma rede conhecidahttp://<PI_IP>:8080 ou http://DAW.local:8080
Hotspot de FallbackSe nenhum Wi-Fi conhecido for encontrado em 25 segundos após a inicializaçãohttp://10.42.0.1:8080 (SSID: ChameleonRecorder, Senha: chameleon123)
Dica: O hotspot de fallback é perfeito para uso em palco e ensaio — sem necessidade de roteador. Apenas conecte seu celular ou laptop diretamente ao Wi-Fi do Pi.

Requisitos do Sistema

ComponenteRequisito
ComputadorRaspberry Pi 4 Model B (64 bits), 2 GB RAM mínimo (4 GB recomendado)
ArmazenamentoCartão microSD (16 GB+) para o SO, pen drive ou SSD (exFAT ou ext4) para gravações
Interface de ÁudioQualquer interface de áudio USB compatível com a classe ou mixer digital (48 kHz)
AlimentaçãoFonte de alimentação USB-C (3A recomendado)

Acesso SSH

Você pode acessar o Raspberry Pi via SSH para configuração avançada e solução de problemas.

ConfiguraçãoValor
Usuáriorecorder
HostnameDAW (DAW.local)
Porta do Controle Web8080
Diretório de Scripts/home/recorder/bin/

Exemplo de comando SSH:

ssh recorder@DAW.local
