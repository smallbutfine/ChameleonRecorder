O que é o ChameleonRecorder?

O ChameleonRecorder é um gravador multitrack WAV headless e plug-and-play que roda num Raspberry Pi 4 (64 bits). Detecta automaticamente qualquer interface de áudio USB compatível com a classe ou console de mixagem digital, grava arquivos WAV multitrack de 24 bits não comprimidos diretamente num pen drive USB, e fornece um controle remoto web amigável para celular com medidores de nível ao vivo.

Sem laptop. Sem DAW. Sem drivers. Apenas um Raspberry Pi, uma interface de áudio USB e um pen drive. Ligue e grave.

Áudio USB Universal

Detecta automaticamente interfaces de áudio USB compatíveis com a classe (Behringer UMC1820, UMC204HD, XR18, X32, MOTU AVB, Focusrite, RME, Zoom) a 48 kHz com fallback de 44.1 kHz.

Gravação Multi-Dispositivo

Grave múltiplas interfaces USB simultaneamente. A interface com mais canais torna-se o mestre JACK; interfaces adicionais são vinculadas via alsa_in com compensação de deriva.

Controle Remoto Web

Controle completo de qualquer navegador de celular, tablet ou laptop na porta :8080. Armamento por dispositivo e por canal, medidores de pico ao vivo, gerenciamento de arquivos e download ZIP.

Hotspot Wi-Fi de Fallback

Se nenhum Wi-Fi conhecido for encontrado em 25 segundos após a inicialização, o ChameleonRecorder cria seu próprio ponto de acesso (SSID: ChameleonRecorder, Senha: chameleon123) em http://10.42.0.1:8080.

Sync de Clock ADAT

Detecta automaticamente sinais de clock ADAT válidos em interfaces Behringer UMC1820 e as alterna para sync de clock ADAT externo para gravação multi-unidade sample-perfeita.

Controles GPIO

Botões físicos opcionais para Gravar/Parar e Apagar Último, mais um LED de status. Ambos os botões pressionados = desligamento seguro.

Conectando o armazenamento

Conecte um pen drive ou SSD formatado como exFAT ou ext4 em uma das portas USB 3.0 azuis. Ele monta automaticamente em /media/usb0. ext4 é recomendado para evitar o limite de tamanho de arquivo de 4 GB do FAT32.

Conectando interfaces de áudio

Conecte sua(s) interface(s) de áudio USB ao Raspberry Pi e ligue-as. O ChameleonRecorder detecta automaticamente todos os dispositivos de áudio USB na inicialização. A interface com mais canais torna-se o mestre JACK; interfaces adicionais são vinculadas via alsa_in.

Word clock multi-interface / sync ADAT

Para gravação sample-perfeita com múltiplas unidades (ex. 2x UMC1820 + 2x ADA8200):

  1. Configure ADA8200 #1 em MASTER 48 kHz e conecte sua WORD CLOCK OUT (BNC 75ohm) à ADA8200 #2 (SLAVE WC IN)
  2. Conecte ADAT OUT da ADA8200 #1 à ADAT IN da UMC1820 #1, e ADAT OUT da ADA8200 #2 à ADAT IN da UMC1820 #2
  3. Configure o botão do painel frontal OPT I/O em ambas as unidades UMC1820 para ADAT
  4. Na inicialização (ou ao pressionar Re-Scan USB Audio Device), o Pi detecta automaticamente o sinal ADAT válido e alterna ambas para sync de clock ADAT externo

Formato de gravação

As gravações são salvas como arquivos WAV de 24 bits não comprimidos a 48 kHz (ou 44.1 kHz se 48 kHz falhar). Cada arquivo é nomeado com um carimbo de data/hora: YYYYMMDD_HHMMSS.wav. Os arquivos são salvos diretamente no pen drive em /media/usb0/.

Dica: Use um pen drive USB 3.0 ou SSD para melhor desempenho. Drives USB 2.0 podem perder amostras durante a gravação multitrack devido a limitações de largura de banda.

Sync de Clock e Gravação Multi-Dispositivo

O ChameleonRecorder suporta a gravação de múltiplas interfaces de áudio USB simultaneamente. O sistema lida automaticamente com a sincronização de clock:

Como funciona

  1. Na inicialização, startcapiture escaneia todas as placas de áudio USB via /proc/asound/cards
  2. As placas são ordenadas por número de canais de captura (decrescente) — a placa com mais canais torna-se o mestre JACK
  3. O servidor JACK primário inicia na placa mestre a 48 kHz (com fallback de 44.1 kHz)
  4. Interfaces adicionais são vinculadas via alsa_in com compensação de deriva adaptativa
  5. Para Behringer UMC1820: se um sinal ADAT válido for detectado na entrada óptica, a fonte de clock é alternada automaticamente para ADAT externo

Detecção de sync de clock ADAT

Quando um UMC1820 é detectado, o ChameleonRecorder verifica o controle Optical In ADAT/SMUX Validity. Se o sinal for válido, define a fonte de clock como 2 (ADAT externo). Se não, define como 0 (interno). Isso acontece automaticamente na inicialização e ao pressionar Re-Scan USB Audio Device.

Compensação de deriva

Quando múltiplas interfaces rodam independentemente (sem conexão de word clock), seus clocks de amostra derivam ligeiramente. O mecanismo alsa_in do JACK fornece compensação de deriva adaptativa — ajusta periodicamente a razão de reamostragem para manter todos os canais sincronizados. Para setups multi-unidade críticos, use uma conexão de word clock ou ADAT para sync sample-perfeita.

Solução de Problemas

Nenhum áudio detectado

  • Verifique se sua interface de áudio USB está conectada e ligada
  • Verifique se a interface é compatível com a classe (sem drivers necessários)
  • Pressione Re-Scan USB Audio Device no controle remoto web
  • Entre por SSH no Pi e execute cat /proc/asound/cards para ver se o dispositivo é detectado
  • Tente uma porta USB diferente (prefira portas USB 3.0 azuis)

O armazenamento USB não monta

  • Certifique-se de que o pen drive esteja formatado como exFAT ou ext4 (não FAT32 ou NTFS)
  • Verifique se o disco está conectado a uma porta USB 3.0 azul
  • Entre por SSH no Pi e execute lsblk para ver se o disco é detectado
  • Verifique dmesg | tail para erros de montagem
  • Tente outro pen drive ou reformate

O hotspot Wi-Fi não aparece

  • Espere pelo menos 25 segundos após a inicialização — o hotspot inicia após um atraso de 25 segundos
  • Se o Pi estiver conectado a uma rede Wi-Fi conhecida, ele NÃO criará um hotspot (isso é por design)
  • Verifique se o código do país Wi-Fi está definido corretamente (padrão DE se não definido)
  • Entre por SSH no Pi e verifique systemctl status wifi-fallback.service
  • Inicie o hotspot manualmente: sudo nmcli device wifi hotspot ifname wlan0 con-name ChameleonHotspot ssid "ChameleonRecorder" password "chameleon123"
