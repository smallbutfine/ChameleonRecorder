Note : Vous n'avez pas besoin d'extraire l'archive .xz — Raspberry Pi Imager la gère directement.

Comment Flasher avec Raspberry Pi Imager

  1. Télécharger l'image : Téléchargez le dernier daw-image.img.xz depuis la page Releases
  2. Ouvrir Raspberry Pi Imager : Téléchargez et lancez le Raspberry Pi Imager officiel sur votre ordinateur Windows, macOS ou Linux
  3. Choisir l'Appareil : Cliquez sur Choose Device et sélectionnez Raspberry Pi 4
  4. Choisir l'OS : Cliquez sur Choose OS, faites défiler vers le bas, sélectionnez Use custom et choisissez le fichier daw-image.img.xz téléchargé
  5. Choisir le Stockage : Insérez votre carte microSD (16 Go ou plus) et sélectionnez-la sous Choose Storage
  6. OS Customisation optionnelle : Cliquez sur Next et choisissez Edit Settings si vous voulez pré-configurer vos identifiants Wi-Fi maison/studio, définir le code pays Wi-Fi, ou ajouter un mot de passe/clé SSH pour l'utilisateur recorder. Si vous sautez cette étape (cliquez sur No), le Pi démarrera automatiquement son hotspot Wi-Fi ChameleonRecorder autonome au premier démarrage
  7. Écrire l'Image : Cliquez sur Yes pour confirmer et attendez que Raspberry Pi Imager termine d'écrire et vérifier la carte SD
  8. Démarrer et Enregistrer : Insérez la carte microSD dans votre Raspberry Pi 4B, connectez votre clé USB et interface(s) audio USB, et allumez-le

Premier Démarrage

  1. Insérez la carte microSD dans le Raspberry Pi 4B
  2. Connectez une clé USB (exFAT ou ext4) à un port USB 3.0 bleu
  3. Connectez votre ou vos interfaces audio USB
  4. Allumez le Pi
  5. Attendez ~25 secondes — si aucun Wi-Fi connu n'est trouvé, le hotspot ChameleonRecorder apparaît
  6. Connectez au hotspot et ouvrez http://10.42.0.1:8080

Hotspot de Secours vs. Wi-Fi Maison

ChameleonRecorder prend en charge deux modes de connexion :

ModeQuand il s'activeURL
Wi-Fi Maison / StudioSi vous avez pré-configuré le Wi-Fi dans Raspberry Pi Imager, ou si le Pi s'est déjà connecté à un réseau connuhttp://<PI_IP>:8080 ou http://DAW.local:8080
Hotspot de SecoursSi aucun Wi-Fi connu n'est trouvé dans les 25 secondes suivant le démarragehttp://10.42.0.1:8080 (SSID : ChameleonRecorder, Mot de passe : chameleon123)
Astuce : Le hotspot de secours est parfait pour la scène et les répétitions — pas besoin de routeur. Connectez simplement votre téléphone ou portable directement au Wi-Fi du Pi.

Configuration Requise

ComposantExigence
OrdinateurRaspberry Pi 4 Model B (64 bits), 2 Go RAM minimum (4 Go recommandé)
StockageCarte microSD (16 Go+) pour l'OS, clé USB ou SSD (exFAT ou ext4) pour les enregistrements
Interface AudioToute interface audio USB conforme ou console numérique (48 kHz)
AlimentationAlimentation USB-C (3A recommandé)

Accès SSH

Vous pouvez accéder au Raspberry Pi via SSH pour une configuration avancée et le dépannage.

ParamètreValeur
Nom d'utilisateurrecorder
Nom d'hôteDAW (DAW.local)
Port de la Télécommande Web8080
Répertoire des Scripts/home/recorder/bin/

Exemple de commande SSH :

ssh recorder@DAW.local
