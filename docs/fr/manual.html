Qu'est-ce que ChameleonRecorder ?

ChameleonRecorder est un enregistreur WAV multitrack headless et plug-and-play qui fonctionne sur un Raspberry Pi 4 (64 bits). Il détecte automatiquement toute interface audio USB conforme ou console de mixage numérique, enregistre des fichiers WAV multitrack 24 bits non compressés directement sur une clé USB, et fournit une télécommande web adaptée mobile avec des vumètres en direct.

Pas de portable. Pas de DAW. Pas de pilotes. Juste un Raspberry Pi, une interface audio USB et une clé USB. Allumez et enregistrez.

Audio USB Universel

Détecte automatiquement les interfaces audio USB conformes (Behringer UMC1820, UMC204HD, XR18, X32, MOTU AVB, Focusrite, RME, Zoom) à 48 kHz avec repli à 44.1 kHz.

Enregistrement Multi-Dispositif

Enregistrez plusieurs interfaces USB simultanément. L'interface avec le plus de canaux devient le maître JACK ; les interfaces supplémentaires sont liées via alsa_in avec compensation de dérive.

Télécommande Web

Contrôle complet depuis n'importe quel navigateur de téléphone, tablette ou portable sur le port :8080. Armement par dispositif et par canal, vumètres de crête en direct, gestion de fichiers et téléchargement ZIP.

Point d'Accès Wi-Fi de Secours

Si aucun Wi-Fi connu n'est trouvé dans les 25 secondes suivant le démarrage, ChameleonRecorder crée son propre point d'accès (SSID : ChameleonRecorder, Mot de passe : chameleon123) à http://10.42.0.1:8080.

Sync d'Horloge ADAT

Détecte automatiquement les signaux d'horloge ADAT valides sur les interfaces Behringer UMC1820 et les bascule sur la sync d'horloge ADAT externe pour un enregistrement multi-unités sample-accurate.

Contrôles GPIO

Boutons-poussoirs physiques optionnels pour Enregistrer/Arrêter et Supprimer la dernière, plus une LED d'état. Les deux boutons maintenus = arrêt sécurisé.

Connecter le stockage

Branchez une clé USB ou un SSD formaté en exFAT ou ext4 sur l'un des ports USB 3.0 bleus. Il se monte automatiquement à /media/usb0. ext4 est recommandé pour éviter la limite de taille de fichier de 4 Go de FAT32.

Connecter les interfaces audio

Connectez votre ou vos interfaces audio USB au Raspberry Pi et allumez-les. ChameleonRecorder détecte automatiquement tous les périphériques audio USB au démarrage. L'interface avec le plus de canaux devient le maître JACK ; les interfaces supplémentaires sont liées via alsa_in.

Word clock multi-interface / sync ADAT

Pour un enregistrement sample-accurate avec plusieurs unités (p. ex. 2x UMC1820 + 2x ADA8200) :

  1. Réglez ADA8200 #1 sur MASTER 48 kHz et connectez sa WORD CLOCK OUT (BNC 75ohm) à ADA8200 #2 (SLAVE WC IN)
  2. Connectez ADAT OUT de ADA8200 #1 à ADAT IN de UMC1820 #1, et ADAT OUT de ADA8200 #2 à ADAT IN de UMC1820 #2
  3. Réglez le bouton de façade OPT I/O sur les deux unités UMC1820 sur ADAT
  4. Au démarrage (ou en appuyant sur Re-Scan USB Audio Device), le Pi détecte automatiquement le signal ADAT valide et bascule les deux sur la sync d'horloge ADAT externe

Format d'enregistrement

Les enregistrements sont sauvegardés en fichiers WAV 24 bits non compressés à 48 kHz (ou 44.1 kHz si 48 kHz échoue). Chaque fichier est nommé avec un horodatage : YYYYMMDD_HHMMSS.wav. Les fichiers sont sauvegardés directement sur la clé USB à /media/usb0/.

Astuce : Utilisez une clé USB 3.0 ou un SSD pour de meilleures performances. Les lecteurs USB 2.0 peuvent perdre des échantillons pendant l'enregistrement multitrack en raison de limitations de bande passante.

Sync d'Horloge et Enregistrement Multi-Dispositif

ChameleonRecorder prend en charge l'enregistrement de plusieurs interfaces audio USB simultanément. Le système gère automatiquement la synchronisation d'horloge :

Comment ça marche

  1. Au démarrage, startcapiture scanne toutes les cartes audio USB via /proc/asound/cards
  2. Les cartes sont triées par nombre de canaux de capture (décroissant) — la carte avec le plus de canaux devient le maître JACK
  3. Le serveur JACK primaire démarre sur la carte maîtresse à 48 kHz (avec repli à 44.1 kHz)
  4. Les interfaces supplémentaires sont liées via alsa_in avec compensation de dérive adaptative
  5. Pour Behringer UMC1820 : si un signal ADAT valide est détecté sur l'entrée optique, la source d'horloge est automatiquement basculée sur ADAT externe

Détection de sync d'horloge ADAT

Lorsqu'un UMC1820 est détecté, ChameleonRecorder vérifie le contrôle Optical In ADAT/SMUX Validity. Si le signal est valide, il règle la source d'horloge sur 2 (ADAT externe). Sinon, il la règle sur 0 (interne). Cela se produit automatiquement au démarrage et en appuyant sur Re-Scan USB Audio Device.

Compensation de dérive

Lorsque plusieurs interfaces fonctionnent indépendamment (sans connexion word clock), leurs horloges d'échantillon dérivent légèrement. Le mécanisme alsa_in de JACK fournit une compensation de dérive adaptative — il ajuste périodiquement le ratio de rééchantillonnage pour garder tous les canaux synchronisés. Pour les configurations multi-unités critiques, utilisez une connexion word clock ou ADAT pour une sync sample-accurate.

Dépannage

Aucun audio détecté

  • Vérifiez que votre interface audio USB est connectée et allumée
  • Vérifiez que l'interface est conforme à la classe (aucun pilote nécessaire)
  • Appuyez sur Re-Scan USB Audio Device sur la télécommande web
  • Entrez par SSH dans le Pi et exécutez cat /proc/asound/cards pour voir si l'appareil est détecté
  • Essayez un port USB différent (préférez les ports USB 3.0 bleus)

Le stockage USB ne se monte pas

  • Assurez-vous que la clé USB est formatée en exFAT ou ext4 (pas FAT32 ni NTFS)
  • Vérifiez que le disque est branché sur un port USB 3.0 bleu
  • Entrez par SSH dans le Pi et exécutez lsblk pour voir si le disque est détecté
  • Vérifiez dmesg | tail pour les erreurs de montage
  • Essayez une autre clé USB ou reformatez

Le hotspot Wi-Fi n'apparaît pas

  • Attendez au moins 25 secondes après le démarrage — le hotspot démarre après un délai de 25 secondes
  • Si le Pi est connecté à un réseau Wi-Fi connu, il ne créera PAS de hotspot (c'est par conception)
  • Vérifiez que le code pays Wi-Fi est correctement défini (par défaut DE s'il n'est pas défini)
  • Entrez par SSH dans le Pi et vérifiez systemctl status wifi-fallback.service
  • Démarrez le hotspot manuellement : sudo nmcli device wifi hotspot ifname wlan0 con-name ChameleonHotspot ssid "ChameleonRecorder" password "chameleon123"
