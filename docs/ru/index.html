Что такое ChameleonRecorder?

ChameleonRecorder — это headless-рекордер многодорожечного WAV, работающий по принципу plug-and-play, который работает на Raspberry Pi 4 (64 бита). Он автоматически обнаруживает любой класс-совместимый USB-аудиоинтерфейс или цифровой микшер, записывает несжатые 24-битные многодорожечные WAV-файлы напрямую на USB-накопитель и предоставляет удобный для мобильных устройств веб-пульт с живыми индикаторами уровня.

Без ноутбука. Без DAW. Без драйверов. Только Raspberry Pi, USB-аудиоинтерфейс и USB-накопитель. Включи и записывай.

Универсальный USB-Аудио

Автоматически обнаруживает класс-совместимые USB-аудиоинтерфейсы (Behringer UMC1820, UMC204HD, XR18, X32, MOTU AVB, Focusrite, RME, Zoom) на 48 кГц с резервом 44.1 кГц.

Многозаписное Захвата

Записывайте несколько USB-интерфейсов одновременно. Интерфейс с наибольшим числом каналов становится мастером JACK; дополнительные интерфейсы привязываются через alsa_in с компенсацией дрейфа.

Веб-Пульт

Полный контроль с любого браузера телефона, планшета или ноутбука на порту :8080. Взвод по устройству и по каналу, живые пиковые индикаторы, управление файлами и ZIP-скачивание.

Резервный Wi-Fi Хотспот

Если в течение 25 секунд после загрузки не найден известный Wi-Fi, ChameleonRecorder создаёт свою точку доступа (SSID: ChameleonRecorder, Пароль: chameleon123) на http://10.42.0.1:8080.

Синхронизация Clock ADAT

Автоматически обнаруживает действительные сигналы часов ADAT на интерфейсах Behringer UMC1820 и переключает их на внешнюю синхронизацию часов ADAT для sample-точной многоблочной записи.

Управление GPIO

Опциональные физические кнопки для Запись/Стоп и Удалить последний, плюс светодиод состояния. Обе кнопки удерживаются = безопасное выключение.

Подключение хранилища

Подключите USB-накопитель или SSD, отформатированный как exFAT или ext4, к одному из синих портов USB 3.0. Он автоматически монтируется в /media/usb0. ext4 рекомендуется, чтобы избежать ограничения размера файла 4 ГБ у FAT32.

Подключение аудиоинтерфейсов

Подключите ваш(и) USB-аудиоинтерфейс(ы) к Raspberry Pi и включите их. ChameleonRecorder автоматически обнаруживает все USB-аудиоустройства при загрузке. Интерфейс с наибольшим числом каналов становится мастером JACK; дополнительные интерфейсы привязываются через alsa_in.

Word clock / ADAT-синхронизация нескольких интерфейсов

Для sample-точной записи с несколькими блоками (например, 2x UMC1820 + 2x ADA8200):

  1. Установите ADA8200 #1 в MASTER 48 кГц и подключите его WORD CLOCK OUT (75ohm BNC) к ADA8200 #2 (SLAVE WC IN)
  2. Подключите ADAT OUT ADA8200 #1 к ADAT IN UMC1820 #1, и ADAT OUT ADA8200 #2 к ADAT IN UMC1820 #2
  3. Установите кнопку на передней панели OPT I/O на обоих блоках UMC1820 в ADAT
  4. При загрузке (или при нажатии Re-Scan USB Audio Device) Pi автоматически обнаруживает действительный сигнал ADAT и переключает оба на внешнюю синхронизацию часов ADAT

Веб-Пульт

Формат записи

Записи сохраняются как несжатые 24-битные WAV-файлы на 48 кГц (или 44.1 кГц, если 48 кГц не удаётся). Каждый файл именуется с временной меткой: YYYYMMDD_HHMMSS.wav. Файлы сохраняются напрямую на USB-накопитель в /media/usb0/.

Совет: Используйте USB 3.0 накопитель или SSD для лучшей производительности. USB 2.0 накопители могут терять сэмплы при многодорожечной записи из-за ограничений пропускной способности.

Синхронизация Clock и Многозаписное Захвата

ChameleonRecorder поддерживает запись нескольких USB-аудиоинтерфейсов одновременно. Система автоматически обрабатывает синхронизацию часов:

Как это работает

  1. При загрузке startcapiture сканирует все USB-аудиокарты через /proc/asound/cards
  2. Карты сортируются по числу каналов захвата (по убыванию) — карта с наибольшим числом каналов становится мастером JACK
  3. Основной сервер JACK запускается на мастер-карте на 48 кГц (с резервом 44.1 кГц)
  4. Дополнительные интерфейсы привязываются через alsa_in с адаптивной компенсацией дрейфа
  5. Для Behringer UMC1820: если на оптическом входе обнаружен действительный сигнал ADAT, источник часов автоматически переключается на внешний ADAT

Обнаружение синхронизации часов ADAT

При обнаружении UMC1820 ChameleonRecorder проверяет регулятор Optical In ADAT/SMUX Validity. Если сигнал действителен, он устанавливает источник часов в 2 (внешний ADAT). Если нет, устанавливает в 0 (внутренний). Это происходит автоматически при загрузке и при нажатии Re-Scan USB Audio Device.

Компенсация дрейфа

Когда несколько интерфейсов работают независимо (без подключения word clock), их тактовые частоты сэмплов слегка дрейфуют. Механизм alsa_in JACK обеспечивает адаптивную компенсацию дрейфа — он периодически корректирует коэффициент ресемплинга, чтобы удерживать все каналы синхронно. Для критичных многоблочных сетапов используйте подключение word clock или ADAT для sample-точной синхронизации.

Установка

Прошить образ ОС

  1. Скачайте последний daw-image.img.xz со страницы Releases
  2. Откройте Raspberry Pi Imager
  3. Выберите Raspberry Pi 4 в качестве устройства
  4. Нажмите Choose OS → Use custom → выберите скачанный .img.xz
  5. Вставьте карту microSD (16 ГБ+) и нажмите Write
  6. *(Опционально)* В настройках OS Customisation предварительно настройте вашу сеть Wi-Fi и код страны. Если пропустить, Pi загружается в автономном режиме хотспота.

Первая загрузка

  1. Вставьте карту microSD в Raspberry Pi 4B
  2. Подключите USB-накопитель (exFAT или ext4) к синему порту USB 3.0
  3. Подключите ваш(и) USB-аудиоинтерфейс(ы)
  4. Включите Pi
  5. Подождите ~25 секунд — если известный Wi-Fi не найден, появляется хотспот ChameleonRecorder
  6. Подключитесь к хотспоту и откройте http://10.42.0.1:8080
