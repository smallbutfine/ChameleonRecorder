Файлы Конфигурации

channels.json

Расположен в /home/recorder/bin/channels.json. Хранит настройки взвода по устройству и по каналу для веб-пульта.

Формат

{
  "devices": {
    "system": true,
    "USB_2": false
  },
  "ports": {
    "system:capture_1": true,
    "system:capture_2": false,
    "USB_2:capture_1": true
  }
}
КлючТипОписание
devicesОбъектОтображение имени устройства на булево (true = включено, false = отключено)
portsОбъектОтображение имени порта JACK на булево (true = взведено, false = не взведено)
Примечание: Если устройство или порт не указаны в конфиге, по умолчанию используется true (включено/взведено).

Как Работает Веб-Пульт

Веб-пульт — это Python HTTP-сервер (web_remote.py), работающий на порту 8080. Он обслуживает одностраничный HTML-интерфейс и предоставляет REST-подобные конечные точки для управления.

HTTP-Сервер

Построен на http.server.ThreadingHTTPServer Python. Слушает на 0.0.0.0:8080.

Как Настроен JACK

JACK (Jack Audio Connection Kit) — это аудиосервер, управляющий всем аудио I/O. ChameleonRecorder настраивает его автоматически через start_jack.

Конфигурация

ПараметрЗначениеОписание
Частота дискретизации48000 Гц (резерв: 44100 Гц)48 кГц предпочтительно; если не удаётся, пробуется 44.1 кГц
Размер буфера (период)2048 кадровБалансирует задержку и стабильность
Периоды (nperiods)3Количество буферов
ДрайверalsaИспользует ALSA для связи с USB-аудиоинтерфейсом

Выбор мастер-устройства

При загрузке start_jack сканирует все USB-аудиокарты через /proc/asound/cards и сортирует их по числу каналов захвата (по убыванию). Карта с наибольшим числом каналов становится мастером JACK. Дополнительные интерфейсы привязываются через alsa_in.

Многоустройственный сетап

# Основной сервер JACK (наибольший интерфейс)
jackd -dalsa -dhw:1 -r48000 -p2048 -n3

# Дополнительные интерфейсы через alsa_in
alsa_in -j "USB_2" -dhw:2 -r48000 -p2048 -n3

Как Работает Обнаружение Синхронизации Часов ADAT

Для интерфейсов Behringer UMC1820 ChameleonRecorder автоматически обнаруживает действительные сигналы часов ADAT и переключается на внешнюю синхронизацию часов.

Процесс обнаружения

  1. start_jack проверяет, имеет ли карта регулятор UMC1820 Clock Selector Clock Source (через amixer)
  2. Если найден, читает регулятор Optical In ADAT/SMUX Validity
  3. Если значение on (действительный сигнал ADAT присутствует), устанавливает источник часов в 2 (внешний ADAT)
  4. Если значение не on (нет действительного сигнала), устанавливает источник часов в 0 (внутренний)

Используемые команды

# Проверить, присутствует ли UMC1820
amixer -c 1 controls | grep "UMC1820 Clock Selector Clock Source"

# Прочитать действительность ADAT
amixer -c 1 cget name='Optical In ADAT/SMUX Validity'

# Установить источник часов на внешний ADAT
amixer -c 1 cset name='UMC1820 Clock Selector Clock Source' 2

# Установить источник часов на внутренний
amixer -c 1 cset name='UMC1820 Clock Selector Clock Source' 0
Примечание: Это обнаружение выполняется автоматически при загрузке и при нажатии Re-Scan USB Audio Device на веб-пульте.

Как Работает Резервный Хотспот

Если в течение 25 секунд после загрузки не найдена известная сеть Wi-Fi, ChameleonRecorder автоматически создаёт точку доступа Wi-Fi.

Процесс

  1. Служба systemd (wifi-fallback.service) запускает /usr/local/bin/wifi-fallback.sh при загрузке
  2. Скрипт ждёт 25 секунд подключения Wi-Fi
  3. Если у wlan0 нет IP-адреса (не подключён), он создаёт хотспот
  4. SSID хотспота — ChameleonRecorder с паролем chameleon123
  5. Веб-пульт доступен по адресу http://10.42.0.1:8080

Конфигурация

# wifi-fallback.sh (упрощённо)
sleep 25
if ! ip -4 addr show wlan0 | grep -q "inet "; then
    nmcli device wifi hotspot ifname wlan0 \
        con-name ChameleonHotspot \
        ssid "ChameleonRecorder" \
        password "chameleon123"
fi
Совет: Если Pi подключён к известной сети Wi-Fi, хотспот НЕ активируется. Это по замыслу — Pi предпочитает ваш домашний/студийный Wi-Fi.
