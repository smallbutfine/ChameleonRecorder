什么是 ChameleonRecorder？

ChameleonRecorder 是一款无头、即插即用的多轨 WAV 录音器，运行在 Raspberry Pi 4（64 位）上。它会自动检测任何类兼容的 USB 音频接口或数字调音台，将未压缩的 24 位多轨 WAV 文件直接录制到 USB 闪存盘，并提供带实时电平表的移动友好网页遥控。

无需笔记本电脑。无需 DAW。无需驱动。只需一个 Raspberry Pi、一个 USB 音频接口和一个 U 盘。开机即录。

通用 USB 音频

自动检测类兼容的 USB 音频接口（Behringer UMC1820、UMC204HD、XR18、X32、MOTU AVB、Focusrite、RME、Zoom），48 kHz，44.1 kHz 回退。

多设备录音

同时录制多个 USB 接口。通道最多的接口成为 JACK 主设备；其他接口通过 alsa_in 绑定并进行漂移补偿。

网页遥控

从任何手机、平板或笔记本浏览器通过 :8080 端口完全控制。按设备和按通道 armed，实时峰值表，文件管理和 ZIP 下载。

备用 Wi-Fi 热点

如果启动后 25 秒内未找到已知 Wi-Fi，ChameleonRecorder 会创建自己的接入点（SSID：ChameleonRecorder，密码：chameleon123），地址 http://10.42.0.1:8080。

ADAT 时钟同步

自动检测 Behringer UMC1820 接口上有效的 ADAT 时钟信号，并将其切换为外部 ADAT 时钟同步，实现采样精确的多单元录音。

GPIO 控制

可选的物理按钮用于录音/停止和删除上一个，外加一个状态 LED。同时按住两个按钮 = 安全关机。

连接存储

将格式化为 exFAT 或 ext4 的 USB 闪存盘或 SSD 插入蓝色 USB 3.0 端口之一。它会自动挂载到 /media/usb0。建议使用 ext4 以避免 FAT32 的 4 GB 文件大小限制。

连接音频接口

将你的 USB 音频接口连接到 Raspberry Pi 并开机。ChameleonRecorder 启动时自动检测所有 USB 音频设备。通道最多的接口成为 JACK 主设备；其他接口通过 alsa_in 绑定。

多接口字时钟 / ADAT 同步

使用多个单元进行采样精确录音（例如 2x UMC1820 + 2x ADA8200）：

  1. 将 ADA8200 #1 设为 MASTER 48 kHz，并将其 WORD CLOCK OUT（75ohm BNC）连接到 ADA8200 #2（SLAVE WC IN）
  2. 将 ADA8200 #1 的 ADAT OUT 连接到 UMC1820 #1 的 ADAT IN，将 ADA8200 #2 的 ADAT OUT 连接到 UMC1820 #2 的 ADAT IN
  3. 将两个 UMC1820 单元前面板的 OPT I/O 按钮设为 ADAT
  4. 启动时（或按下 Re-Scan USB Audio Device），Pi 会自动检测有效的 ADAT 信号并将两者切换为外部 ADAT 时钟同步

网页遥控

网页遥控可从任何浏览器通过 :8080 端口访问。无需在 Pi 上连接屏幕、键盘或鼠标即可完全控制录音。

录音格式

录音保存为未压缩的 24 位 WAV 文件，48 kHz（如果 48 kHz 失败则为 44.1 kHz）。每个文件以时间戳命名：YYYYMMDD_HHMMSS.wav。文件直接保存到 U 盘的 /media/usb0/。

提示：使用 USB 3.0 闪存盘或 SSD 以获得最佳性能。USB 2.0 驱动器可能因带宽限制在多轨录音期间丢失采样。

时钟同步与多设备录音

ChameleonRecorder 支持同时录制多个 USB 音频接口。系统自动处理时钟同步：

工作原理

  1. 启动时，startcapiture 通过 /proc/asound/cards 扫描所有 USB 音频卡
  2. 卡按采集通道数排序（降序）— 通道最多的卡成为 JACK 主设备
  3. 主 JACK 服务器在主卡上以 48 kHz 启动（44.1 kHz 回退）
  4. 其他接口通过 alsa_in 绑定并进行自适应漂移补偿
  5. 对于 Behringer UMC1820：如果在光输入上检测到有效 ADAT 信号，时钟源会自动切换为外部 ADAT

ADAT 时钟同步检测

检测到 UMC1820 时，ChameleonRecorder 检查 Optical In ADAT/SMUX Validity 控件。如果信号有效，将时钟源设为 2（外部 ADAT）。否则设为 0（内部）。这在启动时和按下 Re-Scan USB Audio Device 时自动发生。

漂移补偿

当多个接口独立运行（无字时钟连接）时，它们的采样时钟会轻微漂移。JACK 的 alsa_in 机制提供自适应漂移补偿 — 它定期调整重采样比率以保持所有通道同步。对于关键的多单元设置，使用字时钟或 ADAT 连接以实现采样精确同步。

故障排除

未检测到音频

  • 检查你的 USB 音频接口是否已连接并开机
  • 验证接口是否类兼容（无需驱动）
  • 在网页遥控上按 Re-Scan USB Audio Device
  • 通过 SSH 进入 Pi 并运行 cat /proc/asound/cards 查看是否检测到设备
  • 尝试不同的 USB 端口（优先蓝色 USB 3.0 端口）

USB 存储未挂载

  • 确保 USB 驱动器格式化为 exFAT 或 ext4（不是 FAT32 或 NTFS）
  • 检查驱动器是否插入蓝色 USB 3.0 端口
  • 通过 SSH 进入 Pi 并运行 lsblk 查看是否检测到驱动器
  • 检查 dmesg | tail 的挂载错误
  • 尝试另一个 USB 驱动器或重新格式化

Wi-Fi 热点未出现

  • 启动后等待至少 25 秒 — 热点在 25 秒延迟后启动
  • 如果 Pi 已连接到已知 Wi-Fi 网络，它将不会创建热点（这是设计使然）
  • 检查 Wi-Fi 国家代码是否正确设置（如果未设置，默认为 DE）
  • 通过 SSH 进入 Pi 并检查 systemctl status wifi-fallback.service
  • 手动启动热点：sudo nmcli device wifi hotspot ifname wlan0 con-name ChameleonHotspot ssid "ChameleonRecorder" password "chameleon123"
