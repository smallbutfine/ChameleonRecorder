如何使用 Raspberry Pi Imager 刷写

  1. 下载镜像：从 Releases 页面下载最新的 daw-image.img.xz
  2. 打开 Raspberry Pi Imager：在你的 Windows、macOS 或 Linux 电脑上下载并启动官方的 Raspberry Pi Imager
  3. 选择设备：点击 Choose Device 并选择 Raspberry Pi 4
  4. 选择操作系统：点击 Choose OS，滚动到底部，选择 Use custom，并选择下载的 daw-image.img.xz 文件
  5. 选择存储：插入你的 microSD 卡（16 GB 或更大）并在 Choose Storage 下选择它
  6. 可选的操作系统定制：点击 Next 并选择 Edit Settings，如果你想预先配置家庭/工作室 Wi-Fi 凭据、设置 Wi-Fi 国家代码，或为 recorder 用户添加 SSH 密码/密钥。如果跳过此步骤（点击 No），Pi 将在首次启动时自动启动其独立的 ChameleonRecorder Wi-Fi 热点
  7. 写入镜像：点击 Yes 确认并等待 Raspberry Pi Imager 完成写入和验证 SD 卡
  8. 启动并录音：将 microSD 卡插入你的 Raspberry Pi 4B，连接 USB 闪存盘和 USB 音频接口，然后通电

首次启动

  1. 将 microSD 卡插入 Raspberry Pi 4B
  2. 将 USB 闪存盘（exFAT 或 ext4）连接到蓝色 USB 3.0 端口
  3. 连接你的 USB 音频接口
  4. 给 Pi 通电
  5. 等待约 25 秒 — 如果未找到已知 Wi-Fi，ChameleonRecorder 热点会出现
  6. 连接到热点并打开 http://10.42.0.1:8080

备用热点 vs. 家庭 Wi-Fi

ChameleonRecorder 支持两种连接模式：

模式何时激活URL
家庭 / 工作室 Wi-Fi如果你在 Raspberry Pi Imager 中预配置了 Wi-Fi，或 Pi 之前连接过已知网络http://<PI_IP>:8080 或 http://DAW.local:8080
备用热点如果启动后 25 秒内未找到已知 Wi-Fihttp://10.42.0.1:8080（SSID：ChameleonRecorder，密码：chameleon123）
提示：备用热点非常适合舞台和排练使用 — 无需路由器。只需将手机或笔记本直接连接到 Pi 的 Wi-Fi。

系统要求

组件要求
计算机Raspberry Pi 4 Model B（64 位），最低 2 GB 内存（推荐 4 GB）
存储microSD 卡（16 GB+）用于操作系统，USB 闪存盘或 SSD（exFAT 或 ext4）用于录音
音频接口任何类兼容的 USB 音频接口或数字调音台（48 kHz）
电源USB-C 电源（推荐 3A）

SSH 访问

你可以通过 SSH 访问 Raspberry Pi 进行高级配置和故障排除。

设置值
用户名recorder
主机名DAW（DAW.local）
网页遥控端口8080
脚本目录/home/recorder/bin/

SSH 命令示例：

ssh recorder@DAW.local
