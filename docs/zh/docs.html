脚本参考

所有脚本位于 Raspberry Pi 上的 /home/recorder/bin/。

脚本用途
startcapiture主启动脚本 — 启动 JACK，绑定接口，启动网页遥控
start_jack启动 JACK 音频服务器，自动检测 USB 音频卡，处理 ADAT 时钟同步
rec录音/停止切换 — 启动或停止 jack_capture
del_last删除最近的录音
web_remote.py网页遥控服务器（端口 8080）
jack_meter.py实时峰值电平表守护进程
hotkeysGPIO 按钮事件处理器
steady将状态 LED 设为常亮
blink使状态 LED 闪烁（录音指示）

配置文件

channels.json

位于 /home/recorder/bin/channels.json。存储网页遥控的按设备和按通道 armed 设置。

格式

{
  "devices": {
    "system": true,
    "USB_2": false
  },
  "ports": {
    "system:capture_1": true,
    "system:capture_2": false,
    "USB_2:capture_1": true
  }
}
键类型说明
devices对象设备名到布尔的映射（true = 启用，false = 禁用）
ports对象JACK 端口名到布尔的映射（true = armed，false = 未 armed）
注意：如果设备或端口未在配置中列出，则默认为 true（启用/armed）。

网页遥控如何运作

网页遥控是一个 Python HTTP 服务器（web_remote.py），运行在端口 8080。它提供单页 HTML 界面，并为控制提供类 REST 端点。

HTTP 服务器

基于 Python 的 http.server.ThreadingHTTPServer 构建。监听 0.0.0.0:8080。

端点

端点方法说明
/GET提供网页遥控 HTML 界面
/statusGET返回 JSON：录音状态、JACK 就绪、设备名
/channelsGET返回 JSON：按设备分组的可用 JACK 采集端口，加当前配置
/channelsPOST将通道/设备 armed 配置保存到 channels.json
/levelsGET返回 JSON：所有采集端口的实时峰值电平（dBFS）
/filesGET返回 JSON：/media/usb0/ 中的 WAV 文件列表及大小
/download/<filename>GET下载单个 WAV 文件
/download-allGET将所有 WAV 下载为带时间戳的 ZIP 压缩包
/recPOST开始录音（运行 rec 脚本）
/stopPOST停止录音（向 jack_capture 发送 SIGTERM）
/del_lastPOST删除最近的录音
/rescanPOST重新扫描 USB 音频设备（运行 start_jack）
/delete/<filename>POST删除单个 WAV 文件

JACK 如何配置

JACK（Jack Audio Connection Kit）是管理所有音频 I/O 的音频服务器。ChameleonRecorder 通过 start_jack 自动配置它。

配置

参数值说明
采样率48000 Hz（回退：44100 Hz）优先 48 kHz；如果失败，则尝试 44.1 kHz
缓冲区大小（周期）2048 帧平衡延迟与稳定性
周期数（nperiods）3缓冲区数量
驱动alsa使用 ALSA 与 USB 音频接口通信

主设备选择

启动时，start_jack 通过 /proc/asound/cards 扫描所有 USB 音频卡并按采集通道数排序（降序）。通道最多的卡成为 JACK 主设备。其他接口通过 alsa_in 绑定。

多设备设置

# 主 JACK 服务器（最大接口）
jackd -dalsa -dhw:1 -r48000 -p2048 -n3

# 通过 alsa_in 的额外接口
alsa_in -j "USB_2" -dhw:2 -r48000 -p2048 -n3

ADAT 时钟同步检测如何运作

对于 Behringer UMC1820 接口，ChameleonRecorder 自动检测有效的 ADAT 时钟信号并切换为外部时钟同步。

检测过程

  1. start_jack 检查卡是否有 UMC1820 Clock Selector Clock Source 控件（通过 amixer）
  2. 如果找到，读取 Optical In ADAT/SMUX Validity 控件
  3. 如果值为 on（存在有效 ADAT 信号），将时钟源设为 2（外部 ADAT）
  4. 如果值不是 on（无有效信号），将时钟源设为 0（内部）

使用的命令

# 检查 UMC1820 是否存在
amixer -c 1 controls | grep "UMC1820 Clock Selector Clock Source"

# 读取 ADAT 有效性
amixer -c 1 cget name='Optical In ADAT/SMUX Validity'

# 将时钟源设为外部 ADAT
amixer -c 1 cset name='UMC1820 Clock Selector Clock Source' 2

# 将时钟源设为内部
amixer -c 1 cset name='UMC1820 Clock Selector Clock Source' 0
注意：此检测在启动时和按网页遥控上的 Re-Scan USB Audio Device 时自动运行。

备用热点如何运作

如果启动后 25 秒内未找到已知 Wi-Fi 网络，ChameleonRecorder 会自动创建一个 Wi-Fi 接入点。

过程

  1. 一个 systemd 服务（wifi-fallback.service）在启动时运行 /usr/local/bin/wifi-fallback.sh
  2. 脚本等待 25 秒的 Wi-Fi 连接
  3. 如果 wlan0 没有 IP 地址（未连接），则创建一个热点
  4. 热点 SSID 为 ChameleonRecorder，密码为 chameleon123
  5. 网页遥控可通过 http://10.42.0.1:8080 访问

配置

# wifi-fallback.sh（简化）
sleep 25
if ! ip -4 addr show wlan0 | grep -q "inet "; then
    nmcli device wifi hotspot ifname wlan0 \
        con-name ChameleonHotspot \
        ssid "ChameleonRecorder" \
        password "chameleon123"
fi
提示：如果 Pi 已连接到已知 Wi-Fi 网络，热点将不会激活。这是设计使然 — Pi 优先使用你的家庭/工作室 Wi-Fi。
