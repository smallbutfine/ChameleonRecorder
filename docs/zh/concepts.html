音频录音概念 — 用简单语言解释

本页用现场音响工程师、排练室老板或音乐人能理解的方式解释 ChameleonRecorder 背后的理念。无需编程知识。

1. 什么是多轨录音？

多轨录音意味着将每个输入通道捕获为单独的 WAV 文件。如果你在鼓组上有 16 个麦克风，你会得到 16 个单独的 WAV 文件 — 底鼓一个、军鼓一个、每个嗵鼓一个、overhead、房间麦克风等等。

为什么单独文件很重要

每个通道都是自己的文件。你可以在混音时独立调整每个麦克风的电平、EQ、压缩和效果。如果一切都录成单个立体声混音，没有重新录制，你永远无法修复被埋没的军鼓或轰鸣的底鼓。

你得到什么

每个输入通道一个 WAV 文件，全部在同一时刻开始。将它们拖到任何 DAW（Reaper、Pro Tools、Logic、Ardour 等）中，它们完美对齐 — 每个轨道从第一个采样起就采样同步。

这样想：立体声录音是你混音的照片。多轨录音是原始食材 — 每种乐器在自己的盘子里，随时准备厨师随意调味。
关键点：ChameleonRecorder 将每个 armed 的输入通道录制到自己的 WAV 文件。你通过网页遥控选择要录制的通道。未使用的通道可以省略以节省磁盘空间。

像 ChameleonRecorder 这样的专用录音器用一台专用设备取代了笔记本电脑加 DAW 的设置。为什么这很重要：

笔记本电脑可能在录音中途崩溃、冻结或没电无头 Linux 设备 — 无桌面、无屏保、无后台更新
驱动冲突、操作系统更新和 DAW 许可证检查导致丢音无需安装驱动、无需更新操作系统、无需检查许可证 — 开箱即用
操作系统音频栈和 DAW 插件造成高延迟带低延迟 ALSA 后端的 JACK 音频服务器 — 直接硬件路径
设置时间：打开笔记本、启动 DAW、配置输入、arm 轨道启动即录 — Pi 自动检测你的接口，几秒钟内开始录音

3. USB 音频接口

ChameleonRecorder 与 USB 音频接口配合使用 — 将麦克风和乐器转换为数字音频的盒子。但并非所有 USB 接口都相同。

类兼容 vs. 专有

类型含义示例
类兼容 遵循 USB Audio Class 标准。无需安装驱动即可与任何计算机或设备配合使用。即插即用 — 就像 USB 键盘或鼠标。 Behringer UMC1820、UMC204HD、XR18、X32、MOTU AVB 系列、Focusrite Scarlett（大多数型号）、RME Babyface、Zoom F 系列

重要：ChameleonRecorder 仅支持类兼容的 USB 音频接口。如果你的接口需要从制造商网站下载驱动，它将无法工作。请检查制造商规格中的「USB Audio Class Compliant」或「class compliant」。

4. JACK 音频服务器

JACK（JACK Audio Connection Kit）是 ChameleonRecorder 用来将音频从 USB 接口移动到录音软件的音频路由引擎。把它想成连接一切的中枢神经系统。

JACK 做什么

JACK 从你的 USB 接口获取数字音频流并将其路由到录音应用（jack_capture）。它处理所有时序、缓冲和通道路由，确保每个采样在正确的时间到达正确的位置。

为什么低延迟很重要

延迟是声音输入与系统处理之间的延迟。JACK 比典型计算机音频栈实现低得多的延迟，因为它绕过了操作系统的音频混音器，直接与硬件通信。这意味着没有延迟、没有丢音，即使在重负载下也能可靠录音。

主 / 从概念

当你使用多个 USB 接口时，其中一个必须是时序参考 — 「主」时钟。所有其他接口成为「从」，跟随主时钟的时序。ChameleonRecorder 自动选择通道最多的接口作为主设备。

角色接口作用
主通道最多的接口（例如 UMC1820）设置采样率和时钟。所有其他接口与其同步。
从其他接口（例如第二个 UMC1820、ADA8200）通过 ADAT 或漂移补偿跟随主时钟。
ChameleonRecorder 如何使用 JACK：启动时，系统扫描所有 USB 音频卡，选择通道最多的作为 JACK 主设备，以 48 kHz 启动 JACK 服务器，并通过 alsa_in 绑定其他接口并进行自适应漂移补偿。然后 jack_capture 应用将所有通道录制到单独的 WAV 文件。

5. 时钟同步 — 让一切保持在时间上

当你使用多个音频接口录音时，每个都有自己的内部时钟。即使它们同时开始，也会慢慢分离 — 就像两块表在一个月后相差几秒。这种漂移会在你的多轨录音中造成相位问题和时序错误。

为什么接口会漂移

每个数字音频设备都有一个石英振荡器，决定其采样率。没有两个石英完全一样 — 一个可能运行在 48,000 Hz，另一个在 48,003 Hz。在 10 分钟的录音中，这个微小差异累积成几个采样的漂移，意味着你的轨道慢慢失去同步。

时钟同步解决方案

方法工作原理精度
ADAT 光导 单根光缆从一个设备到另一个同时承载音频和时钟信号。接收设备锁定到发送设备的时钟。采样精确。 采样精确（0 采样漂移）
字时钟（BNC） 专用同轴电缆在设备间仅承载时钟信号。每个设备锁定到字时钟发生器。采样精确。 采样精确（0 采样漂移）
漂移补偿 当没有硬件同步可用时，JACK 的 alsa_in 持续测量接口间的漂移并调整重采样比率来补偿。不是采样精确，但对大多数排练和现场录音情况足够好。 近似（几个采样漂移）
ChameleonRecorder 和 ADAT：当检测到带有效 ADAT 信号的 Behringer UMC1820 时，ChameleonRecorder 自动将其切换为外部 ADAT 时钟同步。这为你提供跨多个单元的采样精确录音，无需任何手动配置。
对于每个采样都很重要的关键录音室工作，始终使用 ADAT 或字时钟。对于排练和现场演示，漂移补偿通常是透明的 — 你不会听到区别。

6. 录音格式 — 24 位 / 48 kHz WAV

ChameleonRecorder 以 24 位分辨率和 48 kHz 采样率录制未压缩的 WAV 文件。这意味着什么以及为什么重要：

24 位 — 动态范围

位深决定你的录音能捕获多少动态范围。24 位给你 144 dB 的理论动态范围 — 远超任何麦克风或前置放大器实际能提供的。这意味着你可以安静地录制，仍然有充足的余量。实际上，24 位意味着即使在非常低的电平下，你也永远不必担心噪声底或量化失真。

48 kHz — 视频标准

48 kHz 是视频制作、电影和电视的标准采样率。如果你的录音将同步视频，48 kHz 是正确选择。它还以充足余量捕获完整的可听频率范围（高达 24 kHz）。44.1 kHz 用于 CD 音频，但 48 kHz 是多轨录音的专业标准。

文件大小

未压缩的 WAV 文件很大。以下是每分钟录音大致需要的空间：

通道每分钟每小时示例
2（立体声）~33 MB~2 GB原声吉他 + 人声
8~132 MB~8 GB完整鼓组
16~264 MB~16 GB带鼓组的完整乐队
32~528 MB~32 GB大型合奏团、管弦乐队
存储提示：一个 64 GB USB 3.0 闪存盘可容纳约 4 小时的 16 轨录音。对于更长的会话，请使用更大的驱动器或 SSD。始终使用 USB 3.0（蓝色端口）— USB 2.0 在多轨录音期间可能丢失采样。
24 位 vs 16 位：16 位（CD 品质）给你 96 dB 的动态范围。听起来很多，但实际上，24 位给你在噪声底之上多约 48 dB 的余量。这意味着你可以保守地设置增益，永远不必担心削波或噪声。始终以 24 位录制。

7. 备用 Wi-Fi 热点

ChameleonRecorder 内置 Wi-Fi 热点，即使没有可用的 Wi-Fi 路由器，你也可以从手机或平板控制它。这对于舞台使用、排练室和远程录音地点至关重要。

为什么重要

大多数场地没有 Wi-Fi，或 Wi-Fi 不可靠。备用热点意味着 ChameleonRecorder 完全自给自足 — 它创建自己的网络并从中提供网页遥控。无需路由器、无需互联网、无需 IT 部门。

工作原理

启动时，ChameleonRecorder 寻找已知 Wi-Fi 网络 25 秒。如果找不到，它会创建自己的接入点，SSID 为 ChameleonRecorder，密码为 chameleon123。将手机连接到此网络，然后在任何浏览器中打开 http://10.42.0.1:8080。

安全考虑

  • 网络隔离：热点是一个独立网络 — 连接的设备无法访问互联网或你的其他网络。
  • 密码保护：默认密码为 chameleon123。如果你在共享空间，请在配置中更改它。
  • 无互联网访问：热点不将流量路由到互联网。它仅提供网页遥控页面。
  • 临时：热点仅在未找到已知 Wi-Fi 时激活。一旦你连接到已知网络，热点自动关闭。
专业提示：如果你在 Wi-Fi 不可靠的场地使用 ChameleonRecorder，备用热点是你的安全网。无论发生什么，你都可以从手机控制录音器。

8. GPIO 控制 — 物理按钮和 LED 状态

Raspberry Pi 有通用输入/输出（GPIO）引脚，ChameleonRecorder 用它们进行物理控制。这意味着你可以录制、停止和删除录音，而无需手机、平板或计算机。

为什么物理按钮很重要

在录音室或舞台上，操作手机应用缓慢且不可靠。你可以不看就按的物理按钮更快、更可靠，即使手机没电或在另一个房间也能工作。这是硬件录音器与应用之间的区别。

LED 状态指示器

状态 LED 给你即时视觉反馈：绿色常亮表示就绪，红色闪烁表示录音，关闭表示关机。你可以从房间另一头看一眼 Pi 就知道其状态，无需解锁手机。

控制动作何时使用
录音 / 停止按钮开始或停止录音快速录音、现场录音、手机不在手边时
删除上一个按钮删除最近的录音当录音被毁且你想立即重录时
同时按住两个按钮安全关闭 Raspberry Pi会话结束 — 安全关机而不损坏文件

设置：GPIO 控制是可选的。如果你不连接按钮，ChameleonRecorder 工作完全相同 — 你只需改用网页遥控。GPIO 引脚是为了方便，而非要求。

阅读图表：你的麦克风插入音频接口。接口通过 USB 将数字音频发送到 Raspberry Pi。JACK 接收它，保持一切同步，并将其传递给 jack_capture，后者将每个通道写入 U 盘上的单独 WAV 文件。整个链条是自动的 — 你只需按录音。

分步

  1. 麦克风 → 音频接口：你的麦克风或乐器连接到接口的前置放大器。接口将模拟声音转换为数字音频。
  2. 音频接口 → USB：数字音频通过 USB 传输到 Raspberry Pi。由于接口是类兼容的，无需驱动 — Pi 立即识别它。
  3. USB → JACK：JACK 接收传入音频并路由它。如果你有多个接口，JACK 使用 ADAT、字时钟或漂移补偿保持它们全部同步。
  4. JACK → jack_capture：jack_capture 应用从 JACK 接收每个通道并将每个写入单独的 WAV 文件。它以 24 位 / 48 kHz 运行。
  5. WAV → U 盘：WAV 文件直接保存到 U 盘的 /media/usb0/。每个文件以时间戳命名，让你确切知道它何时录制。

总结

ChameleonRecorder 是一款专用多轨录音器，用可靠、自主的设备取代了笔记本电脑加 DAW 的设置。它将每个输入通道录制为单独的 24 位/48 kHz WAV 文件，自动处理时钟同步，并让你从任何手机、平板或物理按钮控制。

对于现场音响工程师

将调音台上的每个输入录制为单独轨道。无笔记本电脑、无 DAW、无驱动问题。启动即录。无 Wi-Fi 时使用备用热点。GPIO 按钮用于快速控制。

对于排练室

给每支乐队一份排练的多轨录音。24 位 WAV 文件，他们可以带回家混音。无需录音室时间，无需工程师。只需插入并按录音。

对于音乐人

录制你的乐队、鼓组或完整合奏团。每个通道都是单独文件，准备混音。无需复杂设置 — 如果你能插 USB 线，就能录音。

ChameleonRecorder：插上。开机。按录音。每个通道，每次录音，直接到 USB。
